# kba: Game Boy Advance Emulator

## Usage

```
kba: Game Boy Advance Emulator

Usage: kba -r=ARG -b=ARG [-s]

Available options:
    -r, --rom=ARG    A path to a GBA-compatible ROM file.
    -b, --bios=ARG   A path to the GBA BIOS ROM (necessary for most games).
    -s, --skip-bios  Whether to skip the BIOS boot sequence.
    -h, --help       Prints help information
```

## Installation

- `SDL3` needs to be installed to compile and link this emulator.

  Check your system's package manager for installation instructions.
